# Arkéo BTP

Site vitrine d'Arkéo BTP, artisan maçon à Antibes et alentours.

Site statique (HTML, CSS, JavaScript), sans dépendance externe, publié avec GitHub Pages.

- `index.html` : page d'accueil
- `mentions-legales.html`, `confidentialite.html` : pages légales
- `img/`, `fonts/` : images (photos d'illustration Pexels) et police Manrope (licence SIL OFL)
